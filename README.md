Spotify Promo Workflow by Harmony Hype Verdict & Maluscomas
A free, self-contained HTML tool to help independent musicians plan and execute a Spotify promotion campaign — no sign-up, no install, no backend. Just download and open in any browser.

Features

Pitch Generator — Instantly generate a personalized curator outreach email based on your artist name, track, genre, mood, and bio
5-Week Promo Plan — A structured week-by-week action plan covering pre-release outreach, Spotify editorial submission, social content strategy, and post-release follow-up
Global Outreach Tracker — 180+ contacts across blogs, magazines, radio stations, Spotify playlists, and editorial channels covering 24 genres
Status Tracking — Track each outreach contact through stages: Not Started → Drafted → Sent → Followed Up → Got Response → Placed
No dependencies — Single .html file, works offline, opens in any browser.

How to Use

Download spotify-promo-workflow.html
Open it in any browser (Chrome, Safari, Firefox — no install needed)
Go to the Setup tab and fill in your artist name, track name, genre, mood, release date, and bio
Hit ✦ Generate Pitch to get a ready-to-send curator email
Hit 📅 Build Promo Plan to generate your personalised 5-week campaign
Hit 📋 Load Curators to populate the outreach tracker with genre-specific contacts
Track your outreach status and add notes for each contact

Disclaimer
Contact details and follower counts in the outreach tracker are provided as a starting point for research. Always verify details before reaching out. This tool does not automate any Spotify API actions — all outreach is manual, in compliance with Spotify's Terms of Service.
